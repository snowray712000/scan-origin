### 資料結構

```
- {Current Dir}
  - IOS
    - 261022_72
      - {case foler names}
      - ...
  - Die
    - 261022_34
      - {case foler names}
      - ...
  - 261028_169
    - Bozman_J-Scott-7149-XT-(19)-F-A3
    - Bozman_J-Wickens-7273-XT-(30)-F-D2
    - {case folder names}
    - ... 
  - 261029_92
    - {case folder names}
    - ... 
```

### 說明

- IOS 與 Die 資料夾下的，就是整理分類好的
- dataset 名稱，就是上傳日期與Case數量 {yyMMdd_Count}
- 上面例子，就是處理好某一個日期的上傳，還有兩個待處理

### 判斷準則

- 每個 case folder 中，若存在檔名是 `"xxxxxx-Tooth_{FDI}.stl"` 就是 Die Scan，若沒有，就放在 IOS Scan 中。
- FDI，就是牙齒編號常用的，通常就是 ?? 兩個數字，第 1 個數字，成人牙齒是 1-4 乳牙是 5-8，第 2 個數字，通常就是 1-8。
- Die 實例
  - `Conrad_C-Berry-7155-XT-(4)-F-A3-Tooth_15.stl`
  - `Bozman_J-Wickens-7273-XT-(30)-F-D2-Tooth_46.stl`
  - `Bozman_J-Scott-7149-XT-(19)-F-A3-Tooth_36.stl`
- 非 Die，雖然有 FDI
  - `Dobson_R-Bowers-7155-XT-(29)-F-A3.5-45-crown_cad.stl`
  - `Dobson_R-Bowers-7155-XT-(29)-F-A3.5-45-crown_cad_transform.stl`

### 其它

- 若 Die 或 IOS 資料夾不存在，則自己建
- 這些資料夾的權限設成 777 即可
- 有些 Case 當時處理不好，會變成 {case name}/{case name}/{files}，讓它變成 {case name}/{files}
  - 例如
    - `Bozman_J-Scott-7149-XT-(19)-F-A3/Bozman_J-Scott-7149-XT-(19)-F-A3/{files}` 原本，變成 `Bozman_J-Scott-7149-XT-(19)-F-A3/{files}`
