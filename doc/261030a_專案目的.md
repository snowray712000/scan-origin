### 前言

牙齒的掃描檔分成兩種型別。一種是桌面掃描，這個是在比較古老的牙技師那邊傳下來的。一種是口腔內掃描，直接拿手持式掃描器，直接對著口腔內進行掃描。早期的這種桌面掃描就是翻成石膏模後再進行掃描，而且這石膏模通常會做切Die等操作。

### 動機

要將他人提供的 dataset 分類，因為當時全都上傳在一起，混在一起。

### 目標

- 我需要依據檔案名稱去將這個case分辨它是屬於哪一種哪一種掃描資料，並且將其放到對應位置
- 其它
  - Dataset 統計結果

### 方法

- 使用 Go, 跨平台 scan-origin
- 在 個人筆電開發. 發在 npm (有 organ @cadcam), 到時候從 ubuntu 的電腦下載，去執行
- Go 後端作的很好，再用前端在電筆看

### 使用方法

- 在 dataset 電腦，dataset 資料夾下，呼叫 scan-origin，然後就會開著後端程式
- 在 另一電臘(通常是筆電)，使用 browser 連進剛剛的 ip 與 port
- 功能1
  - 列出 dataset 目前狀態
    - 總計數量，IOS數量，Die數量
    - 詳細
      - 2026-09-10 IOS數量、Die數量
      - 2026-08-01 IOS數量、Die數量
- 功能2
  - 將新上傳的 Dataset 辨斷是哪種Scan，然後再放入合適的資料夾
